# WelcomeWindow

Vendored copy of [CodeEditApp/WelcomeWindow](https://github.com/CodeEditApp/WelcomeWindow) `v1.1.0` (MIT, see [LICENSE.md](LICENSE.md)) for b-code, so the app no longer depends on the upstream repository.

Changes from upstream: the example app, CI files and the SwiftLint plugin dependency are not included, the minimum platform is macOS 27, and file headers use the b-code project name. The module name and public API are unchanged.
